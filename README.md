# Instagram-карусели

Мастер-промт готовит Instagram-карусели под органический охват на холодную аудиторию.

Из исследования твоей аудитории он собирает тексты слайдов, подпись к посту и готовые промты, по которым карусель визуально собирается в Claude Design.

## Для кого создан этот мастер-промт?

Для экспертов, блогеров и предпринимателей, которые растят охваты через Instagram-карусели.

## Как это работает?

Это конструктор каруселей под органический охват, чтобы карусель остановила холодного человека в ленте и довела его до конца.

Сам он слайды не рисует, а готовит всё для сборки в Claude Design: тексты, подпись и точные промты под визуал.

### Глубинное исследование клиента мечты

Промт читает [исследование клиента мечты](https://github.com/BermanRoman/prompt-audience-research) и на этой основе задаёт тон, выбирает маркетинговую нишу _(деньги, отношения или здоровье)_ и генерирует темы, которые закрывают реальные боли клиента.

### Hook

Первый слайд — заголовок до 6 слов, который должен зацепить человека без всякого контекста.

Промт владеет шестью механиками хуков и выдаёт варианты для теста в пробном режиме.

При равных условиях бьёт в страх потери, а не в желание получить.

### Открытая петля

Карусель строится так, что каждый слайд закрывает вопрос предыдущего и открывает новый.

Так у читателя всё время висит незакрытый вопрос, поэтому он листает дальше.

Структура:

1. Хук.
2. Тело хука.
3. Контекст.
4. Развитие.
5. Напряжение.
6. Развязка.
7. CTA.

Всего 7–10 слайдов.

### Нейропаттер-чек

Перед показом промт прогоняет все тексты через нейропаттерн-чек в два прохода:

1. Ищет ИИ-маркеры: канцелярит, штампы, симметричные конструкции и дежурные обороты.
2. Переписывает найденное целиком, а не вычёркивает по слову.

Так карусель не пахнет нейросетью.

### Claude Design

Один раз за проект промт выводит из портрета клиента мечты визуальный стиль и пишет промт дизайн-системы.

Его ты вставляешь в Claude Design, чтобы настроить оформление.

Дальше под каждую карусель он пишет промт карусели в жёстком формате, который собирает готовую карусель в этой дизайн-системе.

В итоге за сессию ты получаешь тексты слайдов, подпись для поста и готовый промт для Claude Design.

## Как пользоваться?

1. Создай новый проект в Claude.
2. Открой файл **instagram-carousels.md,** скопируй его содержимое кнопкой «Copy» и вставь в поле «Инструкции» проекта.
3. Напиши в чате проекта сообщение: _«Начинаем работу по созданию Instagram-каруселей, согласно заложенной в тебя инструкции»_
